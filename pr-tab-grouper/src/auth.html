GitHub と接続

OAuth App の Client ID が一度だけ必要です。
Client ID は公開してよい値で、秘密鍵（Client Secret）は使いません。

OAuth App の作り方（1 分）
  1. github.com/settings/applications/new を開く
  2. Application name … 任意（例: PR Tab Grouper）
  3. Homepage URL … 任意（例: https://github.com/）
  4. Authorization callback URL … 任意（例: https://github.com/）。Device Flow では使いません
  5. 作成後の画面で Enable Device Flow にチェックして Update application
  6. 表示された Client ID を下に貼る

GitHub のタブで承認してください。
