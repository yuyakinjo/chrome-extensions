自分のオープン PR

    GitHub のログイン名。ページから推定するより確実なので、これを最優先で使います。

    バックグラウンド取得

    自分のオープン PR を定期的に取得して、件数バッジ・状態の通知・PR 判定に使います。 GitHub との接続が必要です。

    分

    GitHub を開いていなくても、取得間隔ごとに「1 PR = 1 タブ」になるよう足りないタブだけを裏で開いて グループに入れます。すでに開いているタブや、手でグループから外したタブには触りません。 タブを手で閉じた PR は「非表示」として覚えるので、開き直しません。 要修正・CI 失敗・コンフリクトが来たときだけ戻ってきます（上の一覧の「戻す」でも戻せます）。

    自分の PR だと分かっているタブだけが対象です。GitHub に状態を確認して MERGED / CLOSED だったものだけを閉じます。今見ているタブは閉じません（別のタブへ移ったあとに閉じます）。
