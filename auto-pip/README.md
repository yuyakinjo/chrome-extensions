# Auto PiP

動画を再生しているタブから離れると、Chrome のピクチャインピクチャ（PiP）で
ブラウザの外にも表示できる小さな最前面ウィンドウを自動で開く拡張機能です。
元のタブに戻ると、PiP ウィンドウを閉じます。
タブに戻ったことは Chrome の `tabs.onActivated` でも検知し、ページの表示イベントに
依存せずに解除します。

## インストール

デスクトップ版の **Chrome 142 以上**が必要です。コマンドはリポジトリのルートで実行します。

```sh
bun install
bun run build auto-pip
```

1. `chrome://extensions` を開き、右上の「デベロッパーモード」を ON にする
2. 「パッケージ化されていない拡張機能を読み込む」で **`auto-pip/dist/`** を選ぶ
3. すでに開いている動画のタブを一度再読み込みする
4. 動画を**音声あり**で再生して、別のタブへ移動する
5. Chrome が自動 PiP の許可を尋ねたら、このサイトでの自動表示を許可する

自動表示されないときは、動画サイトのアドレスバー左のサイト情報 →「サイトの設定」で
「自動ピクチャーインピクチャー」を許可してください。頻繁に動画を見るサイトでなければ、
Chrome が最初の許可ダイアログを出さない場合があるため、明示的な許可が必要です。

拡張を更新したら `bun run build auto-pip` を実行し、`chrome://extensions` で拡張を
リロードしたあと、動画のタブも再読み込みしてください。
ポップアップのタイトル横に現在のバージョンが表示されます。今回の修正は **0.1.8** です。
更新前の PiP が開いている場合は、ウィンドウの × で閉じてから更新してください。

## 操作

ツールバーのアイコンから操作できます。

- 自動表示の ON / OFF（初期値は ON）
- このサイトだけ自動表示を OFF（プロトコルとホスト単位で保存）
- 「今すぐPiPで表示」：手動表示は停止中の動画でも利用可能
- 「PiPを解除」：解除専用のボタン。GitHub など別のタブからでも、PiP を開いている動画タブを探して閉じます。すでに解除されていても開き直しません

手動で開いた PiP やサイト側で開いた PiP も、元のタブに戻ると閉じます。
自動表示には Document PiP を優先して使います。動画を小窓へ移し、小窓が閉じると
元の位置に戻します。小窓では Chrome 標準の動画コントロールを表示します。
「今すぐPiPで表示」は通常の動画 PiP を使います。
Document PiP を利用できない場合、または対象の動画が見つからない場合は、
サイト自身が登録している PiP の動作、または通常の動画 PiP を使います。
ON / OFF はこの拡張による自動表示を制御します。タブに戻ったときの PiP 解除は、手動表示でも動作します。
Chrome やサイト自身の自動表示は、それぞれの設定で制御してください。

## 動作条件と制限

自動表示には Chrome の MediaSession の `enterpictureinpicture` を使います。
対応する Chrome では [Document PiP](https://developer.chrome.com/docs/web-platform/document-picture-in-picture)
で動画を表示し、`window.close()` で閉じます。通常の動画 PiP の自動セッションで
`exitPictureInPicture()` が完了しない状況を避けるためです。
閉じたときの `pagehide` で動画の位置、スタイル、コントロールを復元します。
小窓で一時停止した場合は停止した状態で戻します。
解除は動画を開いたページと同じ MAIN world で直接行います。
動画タブでの手動解除は、ボタンのクリックから直接実行し、バックグラウンドへの
メッセージやタブ探索を先に挟みません。自動解除も同じ MAIN の処理を使います。
動画ページの解除 API の Promise を待たず、拡張側で実際の PiP の状態を確認します。
メインフレームを最初に処理し、埋め込み動画では検出した所有フレームだけを解除します。
ISOLATED world は状態確認だけに使います。フレームが破棄された場合は一度再試行します。
解除後は同じフレーム・同じページの状態を読み直します。別フレームの「PiP なし」を
解除成功の根拠にはしません。手動解除は現在のタブを優先し、他の休止中のタブの確認待ちを避けます。
ウィンドウのフォーカス変更だけでは解除しません。ツールバーの操作との競合を避けるためです。
`visibilitychange` から直接 PiP を開く方法では、Chrome が要求するユーザー操作を満たせないため、
Chrome が正式に提供する自動 PiP のアクションから開きます。

Chrome は、動画が再生中で音声フォーカスがあり、直近に音声が出ていること、
動画がトップフレーム内にあること、サイトが Safe Browsing の条件を満たすことなどを確認します。
サイトの明示的な許可がない場合は Media Engagement Index の条件も適用されます。
そのため、**全サイト・無音動画での完全な自動表示は保証できません**。

- iframe 内の埋め込み動画は自動表示の対象外。手動ボタンはアクセスできるフレーム内の動画も探します
- サイトや iframe の Permissions Policy で PiP が禁止されている場合は手動表示もできません
- `disablePictureInPicture` が指定された動画や、読み込み前の動画は選びません
- 複数の動画がある場合は再生中を優先し、その中で表示面積の大きな動画を選びます
- open Shadow DOM に対応。closed Shadow DOM 内の動画にはアクセスできません
- 自動 PiP は、別の PiP がすでに開いていると Chrome から呼ばれない場合があります
- `chrome://`、Chrome ウェブストアなど、拡張の実行が禁止されたページでは動作しません
- PiP ウィンドウの位置・サイズ・字幕表示は Chrome と動画サイトの実装に依存します
- Document PiP は動画要素を別ウィンドウに移すため、サイト独自のコントロールや字幕は小窓には移しません。移動を独自に監視するプレイヤーでは追加の対応が必要な場合があります

公式の条件は [Chrome: 自動 PiP とメディア再生](https://developer.chrome.com/blog/automatic-picture-in-picture-media-playback) を参照してください。

Chrome には [ブラウザ主導の自動 PiP](https://developer.chrome.com/blog/automatic-picture-in-picture-initiated-by-the-browser) もあります。
対応バージョンで `chrome://flags/#browser-initiated-automatic-picture-in-picture` を有効にすると、
拡張なしでも条件を満たすサイトで自動表示できる場合があります。

## 権限と保存する情報

HTTP / HTTPS のページで動画を探すため、サイトへのアクセスを許可します。
`scripting` はポップアップからの状態確認・手動表示とタブ復帰時の解除に、
`activeTab` はポップアップでのタブへのアクセスに、`storage` は ON / OFF と
無効にしたサイトの保存に使います。動画・履歴・設定を外部サーバーへ送信する処理はありません。
カメラ・マイク・デバッガーの権限は使いません。

## 問題が続く場合

ポップアップの「診断結果」に、拡張とページ内スクリプトのバージョン、フレームごとの
PiP 検出結果、直近の解除結果やエラー、解除を呼び出した実行環境を表示します。その内容をコピーして伝えてください。
自動・手動解除の直近の結果は `chrome.storage.session` に保存します。
ポップアップを閉じて開き直しても手動解除の結果を確認できます。ブラウザ終了時に消えます。

## 開発

```sh
bun run dev auto-pip
bun run typecheck
bun auto-pip/tools/make-icons.ts
bun test auto-pip/tests
bun auto-pip/tools/test-chrome.ts
```

`test-chrome.ts` は一時プロファイルのヘッドレス Chrome で、通常 PiP の手動開閉、
Document PiP の手動解除・タブ復帰時の解除、動画の復元、停止状態の保持を検証します。
既存の Chrome プロファイルは使いません。macOS の Chrome 155.0.8059.40 で確認済みです。
別の Chrome バイナリを使う場合は `AUTOPIP_CHROME` に実行ファイルのパスを指定します。
このテストは MediaSession アクションをテスト側から実行します。Chrome の自動表示の
対象判定と YouTube のサイト固有の動作は、実際の動画ページでも確認が必要です。
